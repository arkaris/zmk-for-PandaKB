# Раскладка Sofle — правила и решения

Документ фиксирует **почему** раскладка устроена так, а не как устроен каждый слой построчно.  
Актуальная схема: [`keymap-drawer/Sofle.svg`](../keymap-drawer/Sofle.svg) (генерируется из `Sofle.keymap` при push).

**Контекст:** PandaKB Sofle, nice!nano v2, macOS (иногда SSH в Linux), EN+RU через переключение раскладки ОС, EC11 encoders.

---

## Базовые принципы

### 1. Base похож на обычную клавиатуру

Четыре основных ряда — QWERTY в привычных местах.  
**Зачем:** не ломать слепую печать на EN и RU; мышечная память важнее «оптимизации» ради одной клавиши.

### 2. Русский — через ОС, не через прошивку

Прошивка шлёт US QWERTY scancodes; macOS с русской раскладкой мапит их сам.  
**Зачем:** один Base работает и для EN, и для RU; не нужна Universal Layout на каждой машине; SSH с Mac ведёт себя предсказуемо.

**Следствие для рисовалки:** центр — EN, слева — RU без Shift, сверху — EN+Shift, слева сверху — RU+Shift (если отличается). Цифры `1` `5` `8` `9` `0` и Shift совпадают на EN/RU; у `2`–`4` `6` `7` и части знаков — нет.

### 3. Оба Shift — на Base

Левый и правый Shift остаются на нижнем ряду.  
**Зачем:** в реальной печати используются **оба** — каждый под свою половину клавиатуры; убирать один или переносить Shift на слой нельзя.

### 4. Модификаторы только слева

`Ctrl` · `Alt` · `⌘` — левый thumb. Порядок **как на обычной Mac-клавиатуре** (слева направо, к центру).  
**Зачем:** этими модификаторами пользуюсь **только левой рукой**. Справа модификаторов нет — только **Shift** (правый, на ряду Z).

### 5. Nav и Sym — удержание

**Nav** и **Sym** — `&mo` (слой активен, пока держишь клавишу): F + навигация при Nav; символы + нампад при Sym. **Nav** — левый thumb (`&mo NAV`, слой 1); **Sym** — правый thumb (`&mo SYM`, слой 2). На Nav/Sym activator-клавиши снова `&mo` того же слоя (не `&trans`), чтобы удержание не «проваливалось» в Base. Остальные thumb — `&trans` к Base.  
**Зачем:** навигация и F — левой рукой; символы и нампад — правой; редкие режимы не «залипают».

### 6. Без tap-hold

Tap-hold при печати не используем — только отдельные нажатия.  
**Зачем:** личное предпочтение; меньше случайных срабатываний hold при быстром наборе.

## Текст и пунктуация

### 7. Запятая, точка и `/` — на Base

`,` · `.` · `/` (US) — на нижнем ряду справа.  
**Зачем:** при русской раскладке ОС: `,` → `б`, `.` → `ю`, клавиша `/` (US) → `.` — всё это часто нужно в русском тексте; вынос на слой замедлил бы набор.

### 8. Обратный слэш — на Base

`\` — в правом верхнем углу (как на US-клавиатуре).  
**Зачем:** нужен в программировании постоянно; должен быть на Base в одно нажатие (§11).

### 9. Del — на Nav и Sym (позиция Bksp)

**Base** — `⌫` (Backspace). **Nav** и **Sym** — на той же клавише **Del** (forward delete на Mac).  
**Зачем:** Del нужен при навигации и наборе символов; на Base остаётся привычный Backspace без модификаторов.

## Символы для программирования

### 11. Правило доступности

Каждый символ из списка ниже (§12) — **за 1 или 2 нажатия**. **Nav в расчёт не берём** — там F-клавиши и навигация, не набор символов для кода.

Допустимы только три пути:

1. **Base** — одно нажатие;
2. **Base + Shift** — два нажатия;
3. **Sym** — удержание Sym + клавиша = два нажатия.

### 12. Обязательный набор

`` ` `` · `~` · `-` · `_` · `=` · `+` · `[` `]` · `{` `}` · `\` · `|` · `;` · `:` · `'` · `"` · `,` · `<` · `.` · `>` · `/` · `?` · `@` · `#` · `(` · `)` · `*` · `!` · `$` · `%` · `^` · `&` · цифры `0`–`9`

| Символ | Как (§11) |
|--------|-----------|
| `\` | Base |
| `0`–`9` | Base (верхний ряд) |
| `` ` `` `;` `,` `.` `/` | Base |
| `'` | **Nav** (§14) |
| `"` | **Nav + Shift** (см. «Проблемы») |
| `~` `^` `&` | Base + Shift при EN; **Sym** (`^` `&` `~`) при RU |
| `!` `%` `(` `)` | Base + Shift — **одинаково на EN и RU**; с Sym убраны |
| `@` `#` `$` | **Sym** (на RU Shift+цифры — другие символы) |
| `[ ]` `{` `}` `\|` `-` `=` `+` | Sym |
| `_` | Sym + Shift (`-` на Sym) |
| `\` | **Base** (дубль на Sym убран) |

### 13. Sym — для кода и для RU

На Sym два типа клавиш:

1. **Не помещаются на Base** — `[ ] { }`, `@` `#`, `-` `=` `+`, `\|`, `^` `&` `~`.
2. **Scancode уже есть на Base** — на Sym только `&trans` (тот же HID-код не дублируем): `` ` `` `;` `,` `.` `/`, цифры, буквы, `\` и т.д.
3. **`{` `}` — отдельные клавиши на Sym** (ряд 1 слева): на Base нет; Sym+Shift+`[` `]` = три нажатия, §11 не допускает.

| На Sym | Зачем |
|--------|-------|
| `~` `^` `&` | Shift+цифры на RU ≠ US (отдельных клавиш на Base нет) |
| `@` `#` `$` | Shift+цифры на RU ≠ US |
| `[` `]` | **х** · **ъ** на **`,` · `.`** на **Nav** (scancode `[` `]` на Base нет) |
| `{` `}` | ряд 1 слева — нет на Base |

- **`[` `]`** — **`,` · `.`** на **Nav** (не на Sym). **`{` `}`** — ряд 1 слева на Sym.

**Не на Sym** (scancode уже на Base): `` ` `` `;` `,` `.` `/`, `\`, `!` `(` `)` `%`, `:` `<` `>` `?` `*` — `&trans` или Base + Shift. **`'`** · **`"`** — только **Nav** (§14; **`"`** — см. «Проблемы»).

**Следствие:** при удержании Sym **`;` `,` `.` `/` недоступны** — scancode есть на Base, на Sym `&trans`, а справа нампад. Для **`'`** — Nav; для остальной пунктуации — отпустить Sym.

**RU — `[` `]` (х · ъ):**

| Позиция | Base | Nav |
|---------|------|-----|
| **`,` · `.`** | `,` · `.` · `<` · `>` (Shift) | `[` · `]` → **х** · **ъ** |

**Зачем:** `[` `]` на Nav лежат **поверх `<>`** — те же физические клавиши, что `,` · `.` на Base (со Shift — `<` `>`). Tab◀ · Tab▶ переехали на **N · M**.

```
                         ЛЕВАЯ (символы)              ПРАВАЯ (нампад)
              +---------------------------+  +------------------------------+
ряд 1 (цифры) | { } |                       |  |  7   8   9   −              |
ряд 2 (Q)     | - = + @ # $               |  | (  4   5   6   +              |
ряд 3 (A)     | ▽                         |  | )  1   2   3   *   =          |
ряд 4 (Z)     | ^  &  ~                   |  |    0  ▽,  ▽.  ▽/              |
              +---------------------------+  +------------------------------+
              ▽ = trans к Base              ▽, ▽. ▽/ ▽⇧ — trans с Base (§16)
```

**Зачем:** Sym — символы слева (§13) и нампад справа; Nav для §11 не используется.

## Слои — зачем каждый

### 14. Nav — F-клавиши и навигация

Слой по **удержанию** левого thumb (`&mo`). Слева — F1–F12, справа — навигация:

```
        F1  F2  F3  F4  F5              Home  W◀  W▶  End  PgUp    Del
        F6  F7  F8  F9 F10              ←     ↓     ↑     →    PgDn  ↵
                    F11 F12             Tab◀  Tab▶  [    ]  '
```

Tab◀ · Tab▶ — **N · M**. W◀ · W▶ — второй ряд (U · I). PgUp · PgDn — **P** (мизинец). **Del** — позиция **Bksp** (ряд Q). **Enter** — `&trans` с Base (мизинец home row). **`'`** — ряд Z, кол. **`/`** на Base. **`[` `]`** — ряд Z, **`,` · `.`** на Base.

**Зачем перенос:** `[` `]` — поверх `<>` (§13), не над **N · M**; Tab◀ · Tab▶ удобнее на home-adjacent **N · M**.

| Зона | Клавиши (позиции Base) | macOS |
|------|------------------------|-------|
| **F1–F5** | Ряд Q, cols 1–5 (под `1`–`5`) | функциональные |
| **F6–F10** | Ряд A, cols 1–5 (под `1`–`5`) | функциональные |
| **F11 · F12** | Ряд Z, **V · B** на Base (cols 4–5 слева) | функциональные |
| **Стрелки** | H J K L | vim: ← ↓ ↑ → |
| **Документ** | Home · End; PgUp · PgDn на P | курсор / страница |
| **Слова / вкладки** | W◀ W▶ (U · I); Tab◀ Tab▶ (N · M) | `⌥←/→` · `⌘⌥←/→` |
| **Del** | Позиция **Bksp** (ряд Q) | forward delete |
| **Enter** | Мизинец home row (`&trans` с Base) | ↵ |
| **`'`** | Ряд Z, кол. **`/`** на Base | `'` · `"` (Shift) |

**Зачем:** F и навигация — одной левой рукой; правая — стрелки и навигация по документу.

### 15. Sym — символы и нампад

Слой по **удержанию** правого thumb (`&mo`). Слева — символы для кода (§13), справа — нампад (§16). **Del** — позиция **Bksp** (§9).

**Зачем:** символы и калькулятор — правой рукой; навигация не смешивается с нампадом.

### 16. Sym — нампад вокруг Base

**Главное правило:** нижний ряд нампада **не заменяет** запятую, точку и деление — они **пробиваются с Base** (`&trans`), потому что:

- ввод `1,5` / `3.14` не должен требовать отпускания Sym;
- `/` на том же месте, что на Base;
- правый Shift и Bksp — тоже `&trans`, потому что оба Shift используются.

**Структура справа** (якорь — `,` и `.` на Base):

```
       ▽6   7   8   9  ▽0   −
    (      4   5   6   +  ▽⌫
    )      1   2   3   *   =
           0  ▽,  ▽.  ▽/  ▽⇧
```

- **`0` нампад** — слева от запятой (`M`); отдельная `N0`, не путать с `▽0` цифрового ряда.
- **Цифры 1–9** — столбиком над `0`/`,`/`.`.
- **`6` `0`** верхнего ряда — `&trans` с Base; **`-`** — отдельная клавиша нампада (на Base в этом углу `\`).
- **`(` `)`** — на Sym для удобства; по §11 — Base + Shift (`9`/`0`, EN).
- **`*` над `/`** — умножение вертикально над делением с Base.
- **`+` справа от `6`** — сложение рядом с цифрой блока.
- **=** на мизинец home row — свободная клавиша, не мешает цифрам.
- **Остальные позиции букв** — `&none`, не `&trans`: случайное нажатие не должно печатать `Y`/`H`/`N`.

### 17. Setup — условный слой

Включается, когда **удерживаются** Nav и Sym (`&mo` + `&mo`).  
**Зачем:** редкие действия (BT, громкость, медиа, яркость) не засоряют основные слои; Setup — осознанное сочетание двух thumb одновременно.

**Медиа на левой половине** — три ряда в **cols 2–4** (те же колонки, что W/E/R, S/D/F, X/C/V на Base): безымянный · средний · указательный.

```
        Mute   Vol−   Vol+     ← cols 2–4 (W / E / R)
        ⏪      ⏯      ⏩      ← cols 2–4 (S / D / F)
               Bri−   Bri+     ← cols 3–4 (C / V)
```

- **Громкость** (ряд над home): mute · тише · громче.
- **Медиа** (home): назад · пауза · вперёд.
- **Яркость** (ряд под home): dim · bright — средний и указательный (cols 3–4).

### 18. Encoders — громкость, яркость, клики

| | Поворот | Клик |
|--|---------|------|
| **Левая** | громкость ↑/↓ (инверт.: `C_VOL_DN` / `C_VOL_UP`) | **Mute** (`C_MUTE`) |
| **Правая** | яркость ↑/↓ (инверт.: `C_BRI_DN` / `C_BRI_UP`) | **Mission Control** (`⌃↑`) |

Одинаковые `sensor-bindings` на всех слоях — поворот работает всегда. Клики на Base; на Nav/Sym/Setup — `&trans` (пробиваются с Base).  
**Зачем:** громкость и mute — левой рукой; яркость и Mission Control (обзор окон) — правой, без отрыва от home row.

## Проблемы и ограничения

### `-` и `\` — один физический угол

На полной клавиатуре справа от `0` часто идут `-`, `=`, а `\` — отдельная клавиша. На Sofle в правом верхнем ряду **шесть** клавиш, не семь: **`-` и `\` не помещаются на Base одновременно**.

Оба символа в списке для программирования (§12). Компромисс:

| Символ | Где | Почему |
|--------|-----|--------|
| `\` | **Base** (угол) | §11: в коде — одно нажатие |
| `-` | **Sym** | §11: на Base нет места; Nav не считается |
| `-` | **Sym** (нампад) | Калькулятор; **не** для правила §11 |

На Sym `6` и `0` цифрового ряда — `&trans` с Base; **`-` на Sym — отдельная клавиша**, не trans.

### `'` и `"` — не влезают на Base

На Base мизинец home row занят **Enter** (нужнее в повседневном наборе). Отдельной клавиши под **`'`** на Base нет — пришлось вынести на **Nav** (§14).

| Символ | Как сейчас | Проблема |
|--------|------------|----------|
| `'` | Nav + клавиша | Два действия; Nav в §11 не считается, но для §12 — осознанное исключение |
| `"` | Nav + **Shift** + та же клавиша | **Два модификатора** (удержание Nav + Shift) перед нажатием; по §11 формально три действия вместо двух |

**Компромисс:** Enter на Base; **`'`** реже, но всё ещё нужен в коде — терпим Nav. **`"`** (Shift+`'`) страдает сильнее: при частых строках в коде может понадобиться пересмотр (другая позиция `'` или отдельная клавиша `"` на Sym).
