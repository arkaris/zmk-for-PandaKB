# Раскладка Sofle — правила и решения

Документ фиксирует **почему** раскладка устроена так, а не как устроен каждый слой построчно.  
Актуальная схема: [`keymap-drawer/Sofle.svg`](../keymap-drawer/Sofle.svg) (генерируется из `Sofle.keymap` при push).

**Контекст:** PandaKB Sofle, nice!nano v2, macOS (иногда SSH в Linux), EN+RU через переключение раскладки ОС, EC11 encoders.

---

## Базовые принципы

### 1. Base похож на обычную клавиатуру

Четыре основных ряда — QWERTY в привычных местах.  
**Зачем:** не ломать слепую печать на EN и RU; мышечная память важнее «оптимизации» ради одной клавиши.

### 2. Русский — через ОС, не через прошивку

Прошивка шлёт US QWERTY scancodes; macOS с русской раскладкой мапит их сам.  
**Зачем:** один Base работает и для EN, и для RU; не нужна Universal Layout на каждой машине; SSH с Mac ведёт себя предсказуемо.

**Следствие для рисовалки:** центр — EN, слева — RU без Shift, сверху — EN+Shift, справа — RU+Shift (если отличается). Цифры `1` `5` `8` `9` `0` и Shift совпадают на EN/RU; у `2`–`4` `6` `7` и части знаков — нет.

### 3. Оба Shift — на Base

Левый и правый Shift остаются на нижнем ряду.  
**Зачем:** в реальной печати используются **оба** — каждый под свою половину клавиатуры; убирать один или переносить Shift на слой нельзя.

### 4. macOS-модификаторы слева, слои справа

`Ctrl` · `Alt` · `⌘` · **Sym** — левый thumb; `Space` · NumFn — правый. Порядок Ctrl · Alt · ⌘ **как на обычной Mac-клавиатуре** (слева направо, к центру).  
**Зачем:** `Ctrl` · `Alt` · `⌘` используются **только левой рукой** — на правой их нет. Sym — на свободной клавише левого thumb (между ⌘ и Enter): символы и навигация на время удержания.

### 5. NumFn и Sym — удержание

**NumFn** и **Sym** — `&mo` (слой активен, пока держишь клавишу): нампад/F при NumFn; символы и навигация при Sym. На NumFn/Sym/Setup thumb-клавиши слоёв — `&trans` к Base (не дублируем `&mo`).  
**Зачем:** редкие режимы не «залипают»; одна точка определения активации на Base.

### 6. Без tap-hold

Tap-hold при печати не используем — только отдельные нажатия.  
**Зачем:** личное предпочтение; меньше случайных срабатываний hold при быстром наборе.

## Текст и пунктуация

### 7. Запятая, точка и `/` — на Base

`,` · `.` · `/` (US) — на нижнем ряду справа.  
**Зачем:** при русской раскладке ОС: `,` → `б`, `.` → `ю`, клавиша `/` (US) → `.` — всё это часто нужно в русском тексте; вынос на слой замедлил бы набор.

### 8. Обратный слэш — на Base

`\` — в правом верхнем углу (как на US-клавиатуре).  
**Зачем:** нужен в программировании постоянно; должен быть на Base в одно нажатие (§11).

### 9. Del — комбо, не отдельная клавиша

`Shift + Bksp` → Del (левый или правый Shift).  
**Зачем:** экономия места на маленькой клавиатуре; Bksp и Shift уже на Base; привычная связка для Mac.

## Символы для программирования

### 11. Правило доступности

Каждый символ из списка ниже (§12) — **за 1 или 2 нажатия**. **NumFn в расчёт не берём** — там калькулятор и F-клавиши, не набор символов для кода.

Допустимы только три пути:

1. **Base** — одно нажатие;
2. **Base + Shift** — два нажатия;
3. **Sym** — удержание Sym + клавиша = два нажатия.

### 12. Обязательный набор

`` ` `` · `~` · `-` · `_` · `=` · `+` · `[` `]` · `{` `}` · `\` · `|` · `;` · `:` · `'` · `"` · `,` · `<` · `.` · `>` · `/` · `?` · `@` · `#` · `(` · `)` · `*` · `!` · `$` · `%` · `^` · `&` · цифры `0`–`9`

| Символ | Как (§11) |
|--------|-----------|
| `\` | Base |
| `0`–`9` | Base (верхний ряд) |
| `` ` `` `;` `'` `,` `.` `/` | Base при EN; **Sym** при RU (на Base — `ё` `ж` `э` `б` `ю` `.`) |
| `~` `^` `&` | Base + Shift при EN; **Sym** при RU (Shift+цифры/буквы дают не то) |
| `!` `%` `(` `)` | Base + Shift — **одинаково на EN и RU**; с Sym убраны |
| `@` `#` `$` | **Sym** (на RU Shift+цифры — другие символы) |
| `[ ] { }` `\|` `-` `=` `+` | Sym |
| `_` | Sym + Shift (`-` на Sym) |
| `\` | **Base** (дубль на Sym убран) |

### 13. Sym — для кода и для RU

На Sym два типа клавиш:

1. **Не помещаются на Base** — `[ ] { }` `\|`, `@` `#`, `-` `=` `+`.
2. **Не хватает на русской раскладке ОС** — при RU те же scancodes, что на Base, печатают кириллицу или «не те» символы с Shift. На Sym лежат **US-эквиваленты** для кода:

| На Sym | Зачем (при RU в ОС) |
|--------|---------------------|
| `` ` `` `;` `'` `,` `.` `/` | Base даёт `ё` `ж` `э` `б` `ю` `.` |
| `~` `^` `&` | Shift+цифры на RU ≠ US |
| `@` `#` `$` | Shift+цифры на RU ≠ US (дубли ряда 1) |
| `[` `]` | **х** · **ъ** на **N · M** — `[` `]` рядом (EN); ъ на той же клавише, что **ь** с Base |
| `` ` `` | **ё** над **T** (Е) — N5 на Sym |

**RU-столбики** (на Sym, над буквой Base в той же колонке):

| Столбик | Base (RU) | Sym (US scancode → RU) |
|---------|-----------|-------------------------|
| **T → N5** | Е | `` ` `` → ё |
| **N · M** | Т · **Ь** | `[` · `]` → **х** · **ъ** |

```
                         ЛЕВАЯ (символы)              ПРАВАЯ (навигация)
              +---------------------------+  +------------------------------+
ряд 1 (цифры) | { } |  `                  |  |                              |
ряд 2 (Q)     | - = + @ # $               |  | Home  W◀  W▶  End  PgUp  Fwd |
ряд 3 (A)     | ;  '  ,  .                |  |  ←    ↓    ↑    →  PgDn  Back |
ряд 4 (Z)     | /  ^  &  ~                |  |  [    ]  Tab◀ Tab▶           |
              +---------------------------+  +------------------------------+
                   ё = N5 (над T)            [ ] = N·M; Tab◀ Tab▶ = `<>` (`,` · `.`)
```

- **ё** — N5, над T (Е); **`[` `]`** — **N · M** (х · ъ на RU; квадратные скобки рядом на EN).

**Не на Sym** (есть с Base на EN и RU): `!` `(` `)` `%`, `\` (Base), `:` `"` `<` `>` `?` `*` — через Base + Shift.

**Зачем:** код пишется в EN-символах; при русской раскладке в ОС Sym — короткий путь (удержание + клавиша) без смены языка. NumFn для §11 не используется.

## Слои — зачем каждый

### 14. Sym — символы и навигация

Один слой по **удержанию** левого thumb (`&mo`). Слева — символы для кода (§13), справа — навигация:

```
        Home  W◀  W▶  End  PgUp              Fwd
        (H)    ←     ↓     ↑     →          PgDn  Back
        [    ]   Tab◀  Tab▶
```

Tab◀ · Tab▶ — ряд Z, кнопки `<>` (`,` · `.` на Base). W◀ · W▶ — второй ряд (U · I), над стрелками. PgUp · PgDn — мизинец (P) на 2-м и 3-м рядах, рядом с Fwd/Back. **`[` `]`** — **N · M**. **Enter** — правая большая thumb (Space на Base).

| Зона | Клавиши (позиции Base) | macOS |
|------|------------------------|-------|
| **Стрелки** | H J K L | vim: ← ↓ ↑ → |
| **Документ** | Home · End на 2-м ряду; PgUp · PgDn на P (2–3-й ряды) | курсор / страница |
| **Слова / вкладки** | W◀ W▶ — 2-й ряд (U · I); Tab◀ Tab▶ — ряд Z, `<>` (`,` · `.`) | `⌥←/→` · `⌘⌥←/→` |
| **История** | Fwd на Bksp (2-й ряд), Back под ним (3-й ряд) | `⌘]` / `⌘[` |
| **Enter** | Space (thumb) | ↵ |

**Зачем:** символы и «перемещение» в одном удержании; правая рука — vim-кластер, левая — код и RU-столбики.

### 15. NumFn — F-клавиши и нампад вместе

Слева F1–F12, справа — нампад. Num и Fn объединены.  
**Зачем:** оба нужны редко; один toggle вместо двух; F-клавиши не отнимают место у нампада.

### 16. NumFn — нампад вокруг Base

**Главное правило:** нижний ряд нампада **не заменяет** запятую, точку и деление — они **пробиваются с Base** (`&trans`), потому что:

- ввод `1,5` / `3.14` не должен требовать выключения NumFn;
- `/` на том же месте, что на Base;
- правый Shift и Bksp — тоже `&trans`, потому что оба Shift используются.

**Структура справа** (якорь — `,` и `.` на Base):

```
       ▽6   7   8   9  ▽0   −
    (      4   5   6   +  ▽⌫
    )      1   2   3   *   =
           0  ▽,  ▽.  ▽/  ▽⇧
```

- **`0` нампад** — слева от запятой (`M`); отдельная `N0`, не путать с `▽0` цифрового ряда.
- **Цифры 1–9** — столбиком над `0`/`,`/`.`.
- **`6` `0`** верхнего ряда — `&trans` с Base; **`-`** — отдельная клавиша нампада (на Base в этом углу `\`).
- **`(` `)`** — на NumFn для удобства; по §11 — Base + Shift (`9`/`0`, EN).
- **`*` над `/`** — умножение вертикально над делением с Base.
- **`+` справа от `6`** — сложение рядом с цифрой блока.
- **=** на мизинец home row — свободная клавиша, не мешает цифрам.
- **Остальные позиции букв** — `&none`, не `&trans`: случайное нажатие не должно печатать `Y`/`H`/`N`.

### 17. Sym — символы

См. §14 — отдельного слоя Nav больше нет; символы на левой половине Sym.

### 18. Setup — условный слой

Включается, когда **удерживаются** NumFn и Sym (`&mo` + `&mo`).  
**Зачем:** редкие действия (BT, громкость, медиа, яркость) не засоряют основные слои; Setup — осознанное сочетание двух thumb одновременно.

**Медиа на левой половине** — три ряда в **cols 2–4** (те же колонки, что W/E/R, S/D/F, X/C/V на Base): безымянный · средний · указательный.

```
        Mute   Vol−   Vol+     ← cols 2–4 (W / E / R)
        ⏪      ⏯      ⏩      ← cols 2–4 (S / D / F)
               Bri−   Bri+     ← cols 3–4 (C / V)
```

- **Громкость** (ряд над home): mute · тише · громче.
- **Медиа** (home): назад · пауза · вперёд.
- **Яркость** (ряд под home): dim · bright — средний и указательный (cols 3–4).

### 19. Encoders — громкость и страницы

Левая крутилка: **громкость** ↑/↓ (`C_VOL_UP` / `C_VOL_DN`). Правая: **PgUp** / **PgDn**.  
Одинаковые `sensor-bindings` на всех слоях — крутилки работают всегда, независимо от активного слоя.  
**Зачем:** частые системные действия без отрыва рук от home row; громкость — левой рукой, прокрутка страницы — правой.

## Эволюция (что менялось по ходу)

| Было в плане | Стало | Почему |
|--------------|-------|--------|
| LOWER / RAISE / ADJUST | NumFn · Sym · Setup | Nav влит в Sym |
| Momentary слои | `&mo` NumFn и Sym (+ Nav в Sym) | Оба — на время нажатия |
| Num и Fn отдельно | NumFn | Меньше thumb-клавиш |
| `-`/`\` в одном углу | `\` Base, `-` NumFn, оба Sym | Не помещаются на Base (6 клавиш в ряду) |
| Символы + RU на Sym | Sym только для кода | RU через ОС; Sym не дублирует Base |
| Del на отдельной клавише | Combo Shift+Bksp | Экономия места |
| Encoders | Отключены (EC11=n) | Включены: Vol слева, PgUp/Dn справа |

## Проблемы и ограничения

### `-` и `\` — один физический угол

На полной клавиатуре справа от `0` часто идут `-`, `=`, а `\` — отдельная клавиша. На Sofle в правом верхнем ряду **шесть** клавиш, не семь: **`-` и `\` не помещаются на Base одновременно**.

Оба символа в списке для программирования (§12). Компромисс:

| Символ | Где | Почему |
|--------|-----|--------|
| `\` | **Base** (угол) | §11: в коде — одно нажатие |
| `-` | **Sym** | §11: на Base нет места; NumFn не считается |
| `-` | **NumFn** (нампад) | Калькулятор; **не** для правила §11 |

На NumFn `6` и `0` цифрового ряда — `&trans` с Base; **`-` на NumFn — отдельная клавиша**, не trans.
